# Hyperhodl

Show performance of cryptocurrencies, stocks and currencies against another one, like BTC
https://twitter.com/balajis/status/1339877796902961153

## Commands

### `npm run start`
Start dev server with HMR, using Nollup.

### `npm run start:rollup`
Start dev server with HMR, using Rollup.

### `npm run start:livereload`
Start dev server with livereload.

### `npm run build`
Build

### `npm run serve`
Serve
